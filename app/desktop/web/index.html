Disables recording and spoken replies. Text chat stays available. Speech already playing is stopped; pending synthesis is cancelled before playback.

Open apps

Type or say “open Notepad”, “open Spotify”, or “launch VS Code”. Close matches need a click to confirm.

Hands-free conversation

Hands-free is off. Start it when you are ready to speak. Quiet mode blocks listening and spoken replies.

Conversation

Calendar

Choose an .ics export to include events in briefings. Local snapshots only: import again to refresh. Try calendar today, list calendars, or remove calendar 1. No account connection or calendar edits.

Scheduled daily briefing

Scheduled briefings are off by default. Visual notices only; Artemis must be open. Reopening after the chosen time prepares the current day briefing.

Task plans

Type in chat: plan tasks: what time is it; calculate 25 * 4; open Notepad. Review 2-4 supported steps before clicking Run. App launching is allowed only as the final step. Cancel stops after the current step; completed actions are not undone.

Daily briefing

Weather for your saved city, reminders, and events from imported calendars. Available on request; spoken replies follow Quiet mode and your speech setting.

Reminders

Try “remind me in 10 minutes to stretch”, “show reminders”, or “cancel reminder 1”. Reminders are visual and stay until dismissed. Artemis must be open; overdue reminders appear when you reopen it.

Waiting for the desktop reminder service.

Documents

Add UTF-8 .txt/.md (200 KB), PDF or .docx files (5 MB). Only selected files are read. PDF extraction needs pypdf; image-only scans need OCR, which is not available yet.

Try “search documents for budget”, “list documents”, or “remove document 1”. Indexed text is a local snapshot; select a changed file again to refresh it. Removing it keeps the original file.

Personal memory

Save a fact in chat: “remember that I prefer tea”. Use “show memories”, “find memories about tea”, “update memory 1: I prefer coffee”, or “forget memory 1”. Facts stay on this computer and can inform local chat. Clearing chat does not clear memory; forgetting a fact does not erase old chat messages.

Voice preparation

Optional: prepare cached speech models before a conversation. No recording, playback, downloads or automatic startup. May briefly use CPU and memory. Ready models remain loaded until Artemis closes.

Performance

Timings stay in memory for this session only. No message text or audio is stored here. Recognition totals include time spent recording; speech totals include playback.

Service status

Check local services without recording audio.

Default: artemis. Refresh to list installed models.
